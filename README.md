# ОБЩАГА — НЕ СПАЛИМСЯ

3D социальная дедукция на Unreal Engine 5: 4–8 жильцов общаги тайно выполняют секретные задания, не попадаясь коменданту и не подставляясь друг другу.

## Быстрый старт (Windows)

1. **Склонируйте репозиторий** через GitHub Desktop (File → Clone repository). Путь — без русских букв, например `C:\Projects\obshaga`.
2. **Дважды щёлкните `setup.bat`** в папке проекта. На все запросы Windows отвечайте «Да».
   Скрипт сам поставит Git, Claude Code, Visual Studio 2022 с C++ и Epic Games Launcher.
3. **Если Unreal Engine ещё не установлен,** скрипт откроет Epic Games Launcher. Войдите в аккаунт Epic → **Unreal Engine** → **Library** → **+** → **Install**. Когда установка закончится, снова запустите `setup.bat`.
4. Скрипт соберёт проект и откроет редактор. Затем откройте PowerShell в папке проекта, наберите `claude`, войдите в аккаунт и напишите: **«Продолжаем M0»**.

`setup.bat` можно запускать сколько угодно раз: всё уже установленное он пропускает.

## Что где лежит

| Путь | Что это |
|---|---|
| `CLAUDE.md` | Мастер-ТЗ. Claude читает его в начале каждой сессии |
| `PROGRESS.md` | Журнал: что сделано, что в работе, баги, решения |
| `docs/CONVENTIONS.md` | Как называть файлы, классы и папки |
| `Obshaga.uproject` | Файл проекта Unreal |
| `Source/Obshaga/` | C++-код игры |
| `Content/Obshaga/` | Ассеты: персонажи, предметы, карта, UI, звук, данные, AI |
| `Config/` | Настройки проекта |
| `setup.bat`, `tools/setup.ps1` | Установка всего нужного на Windows |
| `.claude/` | Настройки Claude Code: плагин Unreal и скилы проекта |
| `.mcp.json` | Подключение Claude к открытому редактору Unreal |
